## 🧰 Технологии

**Backend:**
- Python 3
- Django 4.2
- SQLite
- Pillow (обработка изображений)

**Frontend:**
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, keyframe-анимации)
- Vanilla JavaScript (Canvas API, Intersection Observer API)

## ⚙️ Установка и запуск локально

1. Клонируй репозиторий:
```bash
git clone https://github.com/HeyWasup1337/MyPortfolio.git
cd MyPortfolio
```

2. Установи зависимости:
```bash
pip install django pillow
```

3. Примени миграции:
```bash
python manage.py migrate
```

4. Создай суперпользователя (для доступа к админке):
```bash
python manage.py createsuperuser
```

5. Запусти сервер разработки:
```bash
python manage.py runserver
```
